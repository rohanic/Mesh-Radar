# Event packs: verification sheet

The 12 launch packs in `packs/src` ship with `verified: false` (DEC-004). A person checks each pack's dates, facts, phrasebook and advice against the sources below, then sets `verified: true` and runs `npm run packs:build`. `npm run check:release` blocks a production build until every pack is verified.

Researched on 2026-10-20. The research tool could not open pages in this environment, so every entry rests on a search result snippet from the source: open each source before verifying. Islamic dates are Umm al-Qura calculations and can move by a day; Pakistan, India, Bangladesh and Iraq may observe a day later.

Phrasebooks (Arabic, Hindi, Urdu, Bengali, Odia, Nepali) and all advice text were drafted for the packs and need a native speaker and a safety reviewer.
